# Documentation for Vanpuffelen Linux Debian Stable

## Overview

Vanpuffelen Linux is a lightweight Debian-based Linux distribution focused on usability for the common man. I hope for it to become usable on older hardware, too.

## Base

- Debian Stable 

## Desktop

- XFCE
- X11 Recommended
- Wayland... exists

## Default experience

### Layout:
- Default XFCE layout with Vanpuffelen branding ("Default")
- Traditional Windows-like layout ("Traditional")

### Themes:
- Vanpuffelen
- Vanilla XFCE

## Applications

### Default:
- Firefox
- Mousepad
- Default XFCE applications

### Optional:
- LibreOffice
- Steam
- Other

## Goals

- Run well on old hardware
- Keep Debian reliability
- Provide sensible defaults
- Remain user-friendly
- Remain configurable
